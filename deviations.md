# Отклонения от макета (МиграПро)

Все правки сделаны осознанно, для приведения вёрстки к Pixel Perfect и корректной работы адаптива.

---

## 🔧 Блок advantages (преимущества)

### 1. Ширина и колонки сетки
- **Было в макете:** ширина блока 1134px, колонки не описаны.
- **Стало:** `width: 1134px`, `grid-template-columns: 26.3% 20.7% 26.05% 22%`.
- **Причина:** точное совпадение с макетом, но с сохранением адаптивности (на 1380px перестраивается в 2 колонки, на 1111px — в 1).

### 2. Отступы внутри карточек
- **Было в макете:** 15px, 19px, 20px — разные значения.
- **Стало:** `.advantages__item { padding: 19px 0 19px 19px; }`, `.advantages__card { padding: 0 0 0 20px; }`.
- **Причина:** выравнивание по сетке 4px.

### 3. Персональные отступы для 2-й и 4-й карточек
- **Было в макете:** верхний отступ 13px и 27px (не по сетке).
- **Стало:** созданы модификаторы `.advantages__item--pt-13` и `.advantages__item--pt-27`.
- **Причина:** кривизна макета, для точного позиционирования.

### 4. Межстрочные интервалы
- **Было в макете:** 20px, 22px, 26px, 18px — хаотично.
- **Стало:** `.advantages__desc_line-18`, `.advantages__desc_line-21`, `.advantages__desc_line-22`.
- **Причина:** разные значения в макете, вынесены в отдельные классы для точного контроля.

## 📱 Адаптив (правки для мобильных)

### 5. Mobile-first отступы
- **Было в макете:** на мобилке карточки выглядели тесно.
- **Стало:** уменьшены отступы, шрифт 13px, line-height 18-22px.
- **Причина:** улучшение читаемости на мобильных.

### 6. Двойные значения свойств (из-за быстрых правок)
Пример:
```css
.services__list {
  gap: 14px;
  gap: 18px;   /* переопределяет 14px */
}
